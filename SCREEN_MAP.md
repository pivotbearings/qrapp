# Screen Map — Pivot Bearings India

This document maps all attached Stitch design specifications to their native Flutter screens in `pivot_bearings_app`.

| Design Source Directory | Stitch Artifact | Target Platform | Flutter Screen Class | Route Path | Functional Role & Visual Hierarchy |
|---|---|---|---|---|---|
| `customer_home/` | `code.html`<br>`screen.png` | Mobile (iOS/Android) | `CustomerHomeScreen` | `/home` | Main customer dashboard. Contains branded top bar, hero "Scan Bearing QR" card, 3-metric count grid (`Currently IN`, `Currently OUT`, `Active Warranties`), quick inventory link, and recent activity log. |
| `qr_scanner/` | `code.html`<br>`screen.png` | Mobile (iOS/Android) | `QrScannerScreen` | `/scanner` | Optical QR camera scanner. Square viewfinder (max 342px), corner brackets, animated laser line, reticle crosshair, ISO calibration badge, torch toggle, and manual ID dialog fallback. |
| `qr_result_valid_not_activated/` | `code.html`<br>`screen.png` | Mobile (iOS/Android) | `BearingVerificationScreen` | `/bearing/verification` | Bearing verification status. Displays authentic bearing seal, `[STATUS: PENDING ACTIVATION]`, specifications card (ID, batch, warranty duration, activation rule), operational rule alert, and "Confirm Bearing IN" CTA. |
| `in_confirmation_start_warranty/` | `code.html`<br>`screen.png` | Mobile (iOS/Android) | `InConfirmationScreen` | `/bearing/confirm-in` | Installation confirmation. Anchors the authoritative server timestamp, initiates countdown, shows live camera readiness overlay with REC tag, and commits event. |
| `in_success_bearing_marked_in/` | `code.html`<br>`screen.png` | Mobile (iOS/Android) | `InSuccessScreen` | `/bearing/success-in` | Installation success receipt. Confirms active warranty, displays telemetry archive table, start/expiry dates, and proof ID. |
| `out_confirmation_mark_bearing_out/` | `code.html`<br>`screen.png` | Mobile (iOS/Android) | `OutConfirmationScreen` | `/bearing/confirm-out` | Bearing de-installation warning screen. Displays current installation status, installation timestamp, protocol notice, and CTA to capture optical proof. |
| `out_verification_image_capture/` | `code.html`<br>`screen.png` | Mobile (iOS/Android) | `OutVerificationCaptureScreen` | `/bearing/capture-proof` | Dedicated camera viewfinder for de-installation evidence. Reticle vector guide, live camera metadata, and SHA-256 compression engine. |
| `out_result_bearing_marked_out/` | `code.html`<br>`screen.png` | Mobile (iOS/Android) | `OutResultScreen` | `/bearing/success-out` | Operational cycle closure. Displays total operating duration (Days, Hours, Mins), remaining warranty balance, and encrypted proof hash. |
| `admin_dashboard/` | `code.html`<br>`screen.png` | Web / Desktop / Tablet | `AdminDashboardScreen` | `/admin` | Enterprise telemetry operations. Responsive sidebar, search bar, active session status, and 9-metric grid for QR codes, warranties, and customers. |
| `qr_bulk_generation/` | `code.html`<br>`screen.png` | Web / Desktop / Tablet | `QrBulkGenerationScreen` | `/admin/qr-generation` | Bulk QR matrix production. Batch code prefix, lot date, warranty selector, sequential serialization engine, and live vector QR matrix preview. |
| `warranty_assignment/` | `code.html`<br>`screen.png` | Web / Desktop / Tablet | `WarrantyAssignmentScreen` | `/admin/warranty-assignment` | Batch warranty modifier. Bulk overwrite duration (3m, 6m, 12m, 24m), industrial segment assignment, and selection data table. |
| `qr_inventory/` | `code.html`<br>`screen.png` | Web / Desktop / Tablet | `QrInventoryScreen` | `/admin/qr-inventory` | High-density telemetry data grid. Filter tabs (All, Not Activated, IN, OUT, Active, Expired), multi-attribute search, and lifecycle inspect CTA. |
